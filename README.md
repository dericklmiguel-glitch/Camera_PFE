# Atividade 5 - Câmera (Programação Front-End)

Aplicação web desenvolvida com recursos nativos do navegador (`MediaDevices` e `Canvas`) para captura de imagens, aplicação de efeitos visuais dinâmicos e inserção de dados textuais personalizados.

## Recursos Utilizados
* **HTML5 / CSS3:** Estruturação e estilização da interface responsiva.
* **JavaScript (ES6+):** Manipulação do DOM, controle de eventos e lógica de captura.
* **API MediaDevices (`navigator.mediaDevices.getUserMedia`):** Acesso em tempo real à câmera do dispositivo.
* **HTML5 Canvas API:** Processamento gráfico, aplicação de filtros visuais dinâmicos (`context.filter`) e renderização de textos (`context.fillText`).

## Como Executar
1. Clone o repositório ou baixe os arquivos.
2. Certifique-se de executar os arquivos através de um servidor local (como a extensão **Live Server** do VS Code) ou hospedado em um ambiente HTTPS, pois os navegadores exigem segurança para liberar o acesso à câmera (`getUserMedia`).
3. Abra o arquivo `index.html` no seu navegador.
